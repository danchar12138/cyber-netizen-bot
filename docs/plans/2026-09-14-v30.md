版本：2026-09-14-v30
主题：多级告警升级路由、值班策略与通知策略模拟器
状态：已完成

## 给 AI 的开发大纲

### 目标

在现有渠道告警生命周期之上实现可配置的三级升级策略。系统按告警持续时间、严重级别和值班时段选择通知等级与 Adapter，并持久化每次成功升级；管理后台提供无副作用的策略模拟器，使运行参数均可通过配置管理而无需手改配置文件。

### 实现范围

- 新增独立于框架和厂商 SDK 的告警升级策略解析与评估模块，支持三级阈值、严重级别上限、值班时区、工作日、值班时间和非值班 Adapter。
- 生命周期持久化增加当前升级级别和最近升级时间；每次评估最多推进一级，发送任务成功写入 PostgreSQL 后再更新状态。
- 扩展 Agent 运行配置定义、校验、管理 API 与通用配置后台展示；不得返回通知目标或 Secret。
- 异步通知按策略选择 Adapter，幂等键包含生命周期 ID、目标升级级别和 Adapter；不同路由组分批处理。
- 新增通知策略模拟 API，并在渠道管理后台提供输入严重级别、持续时长、当前等级和模拟时间的交互页面，同时展示生命周期当前升级等级。
- 通用可观测告警统一生命周期留到下一阶段。

### 验收标准

- 三级阈值、严重级别上限、跨午夜值班时段和非值班路由的评估结果可测试。
- 重复探测不会重复发送同一级通知，失败或未持久化的通知任务不会提前推进升级级别。
- 配置可在管理后台发布，模拟器仅评估策略且不产生外部副作用。
- 生命周期 API 与后台正确展示升级级别和最近升级时间，并保持租户与 Agent 隔离。
- Python 检查、Alembic 单头和 Web lint/typecheck/test/build 全部通过。
