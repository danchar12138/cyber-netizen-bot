版本：2026-09-16-v49  
主题：告警处置建议安全证据摘要与人工复核效率  
状态：已完成

## 给 AI 的开发大纲

### 目标

在 v48 架构与计划收口后，为管理后台的告警处置建议增加可追溯的安全证据摘要。管理员能够查看建议使用的当前值、阈值、持续时间、发生次数、升级级别和稳健基线聚合数据，快速判断是否接受或驳回建议；系统不保存或返回告警正文、Prompt、Secret、任务载荷或隐藏推理。

### 实现范围

- 在纯 Domain/Application 层增加告警建议证据读模型和确定性 SHA-256 指纹。
- 增加租户与 Agent 隔离的证据查询 API，服务端重新计算当前建议与证据，拒绝跨范围或不存在的生命周期。
- 同步 OpenAPI、生成式 TypeScript SDK、Web API 封装和可观测性管理页面，支持按建议展开证据详情。
- 增加单元、API 集成、Web 单测和 Playwright 主路径覆盖；不新增数据库迁移。

### 关键规则

- 证据只允许固定白名单字段：告警来源元数据、数值/阈值/单位、时间与计数、升级级别、基线中位数/MAD/样本数量、建议原因和护栏。
- 指纹只用于证据定位和前端显示，不作为授权凭证；服务端每次查询都按当前配置和基线重算。
- 证据查询不得触发确认、抑制、通知、配置草稿或其他副作用。
- Domain/Cognition 不依赖 FastAPI、SQLAlchemy、Dramatiq、MinIO SDK 或厂商 SDK。
- 继续保持人工确认、禁止自动执行和当前 Agent 作用域护栏。

### 验收标准

- 活动生命周期可返回与当前建议一致的安全证据摘要和 64 位十六进制指纹。
- 不存在、跨 Agent、非活动或无可用建议的请求得到明确的 404/409/422，不泄露资源信息。
- Web 可展开/收起建议证据，移动端不产生横向溢出，文本不包含敏感正文。
- OpenAPI/SDK、中文标签、测试与文档一致；无数据库迁移。
- Ruff、Pyright、pytest、Web lint/typecheck/test/build、Playwright、OpenAPI 漂移、`git diff --check` 通过。
- 使用中文 Conventional Commit 提交并推送到 `origin/main`。
