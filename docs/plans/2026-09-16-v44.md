## 给 AI 的开发大纲

### 目标

在 v43 冻结反馈和生命周期聚合事实的基础上，增加显式替代动作标签与候选阈值场景回放，为人工调参提供可审计的离线决策支持。不得读取正文、Prompt、隐藏推理、Secret 或任务载荷，不宣称真实因果反事实，不自动调参或发布。

### 实现范围

- 扩展建议反馈契约，安全保存被驳回建议的可选替代动作标签；不保存自由文本。
- 新增候选阈值场景回放领域模型、应用服务和只读 API，复用当前校准窗口、当前生效配置和生命周期的发生次数/持续时间聚合事实。
- 对“持续过久”和“重复警告”两类可归因规则，展示当前阈值与候选阈值下的触发数量、保留数量、避免数量，以及保留样本的采纳/驳回/替代动作统计。
- 生命周期事实缺失、样本不足或候选值未变化时明确标记不可评估；回放不得构造或导出原始业务正文。
- 管理后台提供替代动作选择、场景回放结果、数据口径和人工创建配置草稿入口；草稿仍需配置中心校验、审核和单独发布。
- 同步 PostgreSQL 迁移、数据生命周期导出/清理、OpenAPI、TypeScript SDK、README/运维文档及单元/集成/UI 测试。

### 关键规则

- 回放是基于冻结聚合事实的有界场景模拟，不证明阈值与恢复、业务结果或人工行为之间存在因果关系。
- 所有查询严格限制在当前租户、当前 Agent 和配置校准时间窗内；跨租户、跨 Agent、任意生命周期 ID 和任意阈值键均拒绝。
- 候选值只能来自服务端校准提案或当前值，服务端重新解析配置并校验边界；客户端不得提交任意配置键或执行参数。
- 回放与草稿创建均为只读/显式确认操作，不自动调参、不自动发布、不创建定时任务。
- 替代动作只允许稳定枚举值 `acknowledge`、`suppress`、`observe`，不回传 Secret 或反馈正文。

### 验收标准

- 替代动作反馈的兼容性、权限、租户/Agent 隔离、幂等和数据清理均有测试。
- 回放覆盖候选阈值保持、收紧、无生命周期事实、样本不足、边界值及替代动作统计。
- API、后台、OpenAPI SDK、迁移 head、数据生命周期导出与文档保持一致。
- Ruff、Pyright、pytest、Web lint/typecheck/build、Playwright、OpenAPI 漂移和迁移差异检查全部通过。
- 使用中文 Conventional Commit 提交并推送到 `origin/main`。
