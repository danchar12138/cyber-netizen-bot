# 赛博网友机器人增量开发计划

> 版本：2026-09-10-v7
> 阶段：高精度反思、记忆写入判别与关系校准
> 状态：已完成

## 目标

- 反思任务只保存稳定资源 ID，不在后台任务载荷中复制消息正文或运行配置值。
- 自研认知内核区分稳定偏好、个人事实、重要经历、互动边界、普通提问、寒暄和敏感凭据，减少无价值或危险的长期记忆。
- 关系变化根据感谢、自我披露、纠错、边界和敌意信号进行有界、随当前状态饱和的校准，不再每轮固定增长。
- 将反思策略参数纳入配置中心；后端定义、校验、管理 API 和 Schema 驱动后台表单保持同步。

## 实现大纲

1. 为反思任务增加租户、Agent、用户、会话、消息和 Run 的仓储级复核，只接受已完成 Run 的真实用户消息。
2. 新任务载荷仅携带 Run 与关联实体 UUID；兼容消费升级前已经排队的旧载荷，但不再信任其中的正文与阈值。
3. 在纯认知包实现可回放的记忆决策、类别、原因码、关系信号和饱和增量算法；凭据类内容永不生成长期记忆或逐字来源副本。
4. Episode、记忆和关系事件 ID 改由 Run ID 确定性生成，使 Worker 重投与人工重放不产生重复副作用。
5. 新增高精度/均衡记忆策略及正向、负向、熟悉度步长配置，复用现有配置发布、差异、回滚和后台表单。
6. 后台中文显示层补齐新增关系事件与安全结果字段；README 记录任务载荷边界和反思行为。

## 验证与完成标准

- 覆盖偏好、事实、计划、边界、寒暄、普通提问、纠错、敌意和凭据内容的确定性判别。
- 覆盖跨租户/Agent/用户/会话拒绝、已删除会话拒绝、旧任务兼容和跨任务重放幂等。
- 任务记录、结果摘要、日志和 Trace 不新增消息正文、凭据、对象键、Prompt 或远端响应。
- Python 使用 `uv` 通过格式、Ruff、Pyright 和全量测试；Web 通过类型、测试、构建和 Playwright。
- README 与计划状态同步，并使用带中文描述的 Conventional Commit 独立提交。

## 暂不包含

- 不调用模型生成反思结论；后续模型增强必须通过结构化契约、回放评测和确定性策略门。
- 不实现长对话分层摘要和多模型反思对比；它们在本阶段建立的安全来源与决策契约上继续演进。
- 不接入飞书、Discord 或 Telegram 的真实 API。
