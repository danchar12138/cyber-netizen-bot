# 赛博网友机器人开发计划

版本：2026-09-15-v42
主题：告警建议反馈与质量统计
状态：已完成

## 给 AI 的开发大纲

### 目标

承接 v41 的只读处置建议，记录管理员的采纳或驳回反馈，并联合同窗口重放复核结果提供可审计质量统计；不自动执行、不自动调参。

### 实现范围

- 新增租户与智能体隔离的追加式建议反馈，按生命周期唯一，仅保存采纳/驳回结论、服务端重算的建议动作、优先级、原因码和操作人元数据。
- 反馈 API 不接收建议自由文本；采纳确认/抑制前必须已完成匹配的人工处置，驳回与采纳观察均不触发任何处置。
- 新增只读质量统计 API，展示反馈总量、采纳率、动作/来源分布及同窗口允许/阻止重放数，不将相关性表述为因果。
- 管理后台支持采纳“继续观察”、驳回建议、查看质量概览；采纳可执行建议仍先走现有人工确认处置 API。
- 将反馈记录纳入安全历史导出与保留期清理，同步迁移、领域/契约、OpenAPI SDK、中文文案、手册和全层测试。

### 关键规则

- 同一告警生命周期只接受一次反馈；相同请求幂等返回，冲突结论明确拒绝。
- 服务端以当前生命周期、稳健基线和版本化配置重算建议，客户端不能提交或覆盖动作、原因码、优先级与置信度。
- 有反馈的生命周期不再重复返回建议；新生命周期产生新的独立建议。
- 反馈不保存业务正文、处置自由文本、通知目标、Secret、Prompt、隐藏推理或任务载荷。

### 验收标准

- 采纳、驳回、幂等、冲突、跨租户/智能体与处置匹配护栏均有测试。
- 质量统计口径确定、窗口有界，管理后台不暴露敏感信息，不提供自动执行或自动调参入口。
- 反馈保留期通过配置中心定义、校验、管理 API 和通用后台管理，安全导出与清理计数保持对齐。
- Ruff、Pyright、pytest、Web 完整检查、Playwright、OpenAPI 漂移、迁移 head 与差异检查全部通过，并使用中文 Conventional Commit 独立提交。

### 完成结果

- 已落地反馈领域模型、内存/PostgreSQL 仓储、并发幂等、管理 API、审计事件、质量聚合与迁移 `20260915_0034`。
- 已完成管理后台反馈和质量概览；可执行建议严格先人工处置再记录采纳，失败重试不会重复处置。
- 安全历史导出升级为 `cnb-observability-alert-history-v2`，反馈保留期已接入配置中心、清理和后台展示。
- Ruff、Pyright、`364` 个 Python 测试、`30` 个 Web 单元测试、生产构建与 `22` 个 Playwright 用例通过；OpenAPI 为 `166` 个操作，迁移唯一 head 为 `20260915_0034`，差异检查通过。
