# 赛博网友机器人开发计划

版本：2026-09-17-v54

主题：评测决策审批、Ed25519 签名证明与只读发布关联

状态：开发完成

## 给 AI 的开发大纲

### 目标

在 v53 不可变评测决策之上增加职责分离的人工审批。审批结论、决策摘要和可选发布变更引用冻结为 Ed25519 签名证明，可下载并由服务端独立复核；整个流程只记录治理事实，不调参、不改配置、不执行发布。

### 实现范围

- 增加不可变审批领域类型、内存/PostgreSQL 仓储、审计事件和数据库迁移。
- 每个决策最多一份终态审批；审批人不得是决策创建人；等待更多证据的决策不得批准。
- 增加 `evaluation:approve` 独立权限，仅管理员持有；查看沿用 `cognition:read`，证明下载额外要求 `data_lifecycle:export`。
- 使用 Agent 作用域 SecretStore 中的 Ed25519 私钥签署 canonical JSON；只公开算法、公钥、key id、签名和摘要，永不回显私钥。
- 支持批准或驳回、受控原因，以及可选的开发/预发布/生产环境与变更编号只读关联；关联不得调用配置或发布服务。
- 提供审批创建、读取、签名验证和原始 JSON 证明下载 API，同步 OpenAPI 与生成式 TypeScript SDK。
- 管理后台在评测决策详情中完成审批、查看证明、校验签名和下载；配置中心可管理签名私钥。
- 覆盖领域服务、PostgreSQL 约束/API 权限、Web 客户端与 Playwright 主路径。

### 关键规则

- Domain/Cognition 不依赖 FastAPI、SQLAlchemy、Dramatiq、Cryptography 或厂商 SDK；签名能力通过应用端口注入，由基础设施实现。
- 签名私钥只允许 32 字节 Base64 Ed25519 seed，存入加密 SecretStore；轮换后旧证明仍可用证明内公钥验证。
- 证明签署决策 ID、决策 SHA-256、审批结论、原因、审批人、时间和发布引用；证明原始字节与 SHA-256 持久化后不得重算或修改。
- 驳回审批不得关联发布变更；批准“等待更多证据”决策、重复审批、自审、无签名密钥或非法变更编号都必须拒绝。
- 发布引用仅为不可变字符串事实，不读取远端地址，不授予发布能力，也不允许审批触发自动动作。
- API、日志、审计、导出和配置差异不得出现私钥、Prompt、回答正文、评审备注或隐藏推理。

### 验收标准

- 两名不同管理主体可完成决策与审批；自审、重复审批和越权审批被服务端拒绝。
- 签名证明可验证原始字节、payload 摘要、Ed25519 签名、key id 和所关联决策摘要；任一内容篡改后验证失败。
- 密钥轮换不破坏历史证明验证，私钥不出现在任何响应、日志、导出或审计记录中。
- 管理后台可审批、查看发布关联、验证和下载证明，缺少权限时不显示写入或下载入口。
- OpenAPI/SDK、数据库迁移、配置定义、中文标签、测试和文档一致，唯一迁移 head 更新。
- Ruff、Pyright、pytest、Web lint/typecheck/test/build、Playwright、OpenAPI 漂移、迁移检查和 `git diff --check` 通过。
- 使用中文 Conventional Commit 提交并推送到 `origin/main`。

## 范围收口

v54 是当前已授权核心范围的最终版本。多审批人策略、外部 KMS/HSM 签名器和真实发布系统状态回读不属于当前范围；在收到新的明确业务目标、优先级和验收标准前，不新增计划版本或继续扩展功能。最终状态以总进度概览为准。

- 已完成不可变审批领域类型、应用服务、内存/PostgreSQL 仓储、审计事件和迁移 `20260917_0037`；每个决策最多一份终态审批，并由数据库唯一约束兜底。
- 已增加 `evaluation:approve` 独立权限和审批创建、读取、服务端验证、原始证明下载 API；自审、重复审批、越权审批、非法结论组合和不完整发布引用均由服务端拒绝。

- 管理后台已支持审批、发布引用填写、证明详情、服务端验签与权限化下载，并明确展示职责分离和无自动发布边界；桌面与移动端主路径均已覆盖。
