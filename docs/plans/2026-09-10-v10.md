# 赛博网友机器人增量开发计划

> 版本：2026-09-10-v10
> 阶段：v2 完成证据、中文语境与 MinIO 架构治理收口
> 状态：已完成（外部治理项除外）

## 目标

- 补齐 v2 P0 要求但尚未落库的首批架构决策记录，使关键边界具备可追溯依据。
- 将 Domain/Cognition 框架独立、MinIO 唯一对象存储和禁止 AWS 客户端依赖转为自动化架构契约。
- 收口仍可自然中文化的 OIDC 默认租户名和对象存储故障手册表述。
- 汇总 v2 P0 至 P7 的完成证据，并如实记录 GitHub 私有仓库套餐导致的 `main` 分支保护外部治理项。

## 实现大纲

1. 新增模块化单体与自研认知核心、数据库配置真相与密钥边界、MinIO 唯一对象存储三份中文 ADR。
2. 新增 AST 与项目清单架构契约测试，禁止 Domain/Cognition 引入 FastAPI、SQLAlchemy、Dramatiq、MinIO 或模型厂商 SDK，禁止项目声明 AWS 对象存储客户端依赖。
3. 校验启动设置的对象存储字段仅使用 `minio_*` 命名；MinIO SDK 的兼容协议异常类型不作为 AWS 实现误报。
4. 将默认 OIDC 租户显示名统一为“赛博网友租户”，并移除运行手册中暗示可切换其他对象存储实现的表述。
5. 更新 README 的最新计划入口与架构决策入口。
6. 修复远端基础设施验收发现的评测运行父记录与用例结果外键写入顺序，并增加 PostgreSQL 仓储路径回归测试。

## 验证与完成标准

- 架构契约测试能够准确拦截核心包越界依赖、AWS 客户端依赖和非 MinIO 启动字段，同时允许 MinIO SDK 自身的兼容协议类型。
- 三份 ADR 与当前代码、配置、部署和测试一致；README 可以直接定位最新计划和架构决策。
- Python 使用 `uv` 通过格式、Ruff、Pyright 和全量测试；Web 通过类型、单测、构建和 Playwright；Alembic 保持单 head。
- 使用带中文描述的 Conventional Commit 独立提交并推送，远端 CI 通过。
