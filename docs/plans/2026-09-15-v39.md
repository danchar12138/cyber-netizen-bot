## 给 AI 的开发大纲

### 目标

在通用告警生命周期与安全历史基础上，提供当前 Agent 的稳健异常基线和可直接用于值班交接的运营摘要。

### 实现范围

- 增加基线窗口、历史周期数、异常灵敏度和最小当前事件数的版本化配置，管理员可在配置中心管理。
- 用等长历史窗口中位数与 MAD 计算开启量、升级量的稳健基线，同时给出全局与来源级异常信号。
- 生成值班交接摘要：活动、严重、未确认、已抑制、近期开启/恢复/升级、阻止重放、来源聚合与优先关注项。
- 新增租户与 Agent 隔离的只读 API，同步 OpenAPI 客户端、中文管理后台、运行手册和测试。
- 摘要只使用计数、告警定位字段、处置状态和稳定原因码，不返回处置备注、任务载荷、通知目标、Secret、Prompt、隐藏推理或业务正文。
- 单次摘要最多精确处理 10000 条生命周期和 10000 条处置记录，仓储使用“上限 + 1”检测溢出并明确拒绝，禁止无界加载或静默截断。

### 验收标准

- 稳健基线算法在零基线、异常历史值和来源分组下结果稳定，且不受其他租户或 Agent 影响。
- 交接摘要计数与优先级排序准确，过期抑制视为未处置，重放阻止数限定在当前交接窗口。
- 新配置可版本化校验和发布，API、Web、文档与生成客户端一致，完整检查通过。

### 实际验收

- 全仓 `uv run poe check` 通过：357 项后端测试全部成功，覆盖率 76%，Ruff 与 Pyright 无错误。
- Web 完整检查通过：OpenAPI/生成客户端无漂移，ESLint、TypeScript、28 项测试和生产构建全部成功。
- OpenAPI 共 163 个操作；数据库迁移保持单一 head `20260915_0033`，本阶段无需新增迁移。
- 桌面与 390×844 移动端实页检查通过，初始视口无顶栏遮挡或横向溢出。
