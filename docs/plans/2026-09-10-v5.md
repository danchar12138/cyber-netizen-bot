# 赛博网友机器人增量开发计划

> 版本：2026-09-10-v5
> 状态：外部身份与可重放入站 Inbox 已完成

## 当前完成情况

- Web 是统一管理后台，内部全功能对话是其中一个功能页。
- 自研 Agent 认知运行时、长期记忆、关系、主动行为、评测、多模态输入和可观测性已形成可运行纵向闭环。
- 多 Agent 创建、复制、全局切换和数据隔离已完成；渠道实例不可变绑定 Agent。
- Agent 支持重命名、九类关联资源影响预览、逐字确认归档和逐字确认软删除。
- 归档立即阻断新运行、停用所属渠道并取消待执行主动行为；已归档和已删除 Agent 不能被客户端选择。
- 软删除记录 `deleted_at`、`purge_after`，保留天数由 `data.retention.deleted_agent_days` 通过配置中心管理。
- 管理 API 不执行 Agent 物理删除；达到 `purge_after` 后，只有显式确认的数据保留期清理会先删除 MinIO 私有对象，再在数据库事务内清理 Agent 及关联记录。
- 外部主体与会话/线程已建立租户与 Agent 双重隔离的显式映射。
- 版本化净化 Envelope、PostgreSQL Inbox/Outbox 幂等落库、`inbound` Worker 队列和安全重放已完成。
- 管理后台已支持映射管理、Inbox 安全摘要和重放；不展示正文、凭证、对象键或远端响应。
- 当前 Worker 冻结在 `ready_for_agent` 路由边界，尚不创建真实对话消息或 Agent Run。
- 当前 Alembic head：`20260910_0019`。

## 本版本已完成：外部身份与可重放入站 Inbox

目标是在飞书、Discord、Telegram 仍保持零外部副作用占位的前提下，先冻结真实 IM 接入所需的数据契约和路由边界。

1. 外部身份映射
   - 建立租户、Agent、渠道实例、平台主体与本地用户的显式映射。
   - 平台、渠道实例、外部主体 ID 组合唯一；跨租户或跨 Agent 查询统一按不存在处理。
   - 管理后台支持查询、绑定、停用和冲突诊断，不允许手改配置文件。

2. 会话线程映射
   - 建立平台会话/群、线程、消息与内部 Conversation 的稳定映射。
   - 群聊、私聊、线程回复采用明确策略，禁止用显示名称作为身份或路由键。
   - 映射变更只记录安全标识摘要，不记录消息正文、凭证或远端原始响应。

3. 可重放 Inbox 契约
   - 入站 Envelope 固定 schema version、渠道、Agent、外部事件键、主体、会话、线程、消息和多模态引用。
   - 原始事件先完成签名/时效校验、大小限制、规范化和幂等落库，再投递后台任务。
   - 重放使用已净化的标准 Envelope，不重新接受不可信原始载荷；重复事件不得重复生成会话消息或 Agent Run。

4. 管理与观测
   - 后台展示身份映射、线程映射、Inbox 状态、重试和死信，不展示正文和密钥。
   - 新运行设置同步定义、验证、管理 API 与后台 UI。
   - 更新 DDL、ORM、Repository、契约、OpenAPI 生成客户端、测试和 README。

5. 验证
   - 单元测试覆盖规范化、映射冲突、幂等和重放。
   - API 集成测试覆盖租户与 Agent 双重隔离、跨作用域拒绝和权限。
   - Playwright 覆盖后台映射管理和 Inbox 诊断。
   - 保持 API、Worker、Web 可运行，Python 使用 `uv`，Web 使用 Corepack 固定 pnpm。

## 不在下一阶段范围

- 不调用飞书、Discord 或 Telegram 真实 API。
- 不保存远端凭证明文、消息正文副本、对象键、完整 Prompt 或隐藏推理到日志、Trace、诊断或导出。
- 不开放绕过 Policy Gate 的外部发送能力。
