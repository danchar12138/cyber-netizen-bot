## 给 AI 的开发大纲

### 目标

以 `2026-09-09-v2.md` 的 P0 至 P7 为原始验收范围，以 `2026-09-09-v3.md` 的 MinIO 唯一对象存储修订和当前仓库事实为准，消除项目总览中的版本漂移，并把中文优先开发语境固化为自动化约束。

### 实现范围

- 保留历史计划，不回写当时的技术选型与进度；README 指向本阶段最新计划，并同步实际 Alembic head 和 v39 已完成能力。
- 手写 Python 模块、类与函数文档字符串默认使用自然中文；叙述性代码注释使用中文，协议字段、品牌名、代码标识和工具指令保留行业惯例。
- 增加源码级中文语境测试，排除 OpenAPI 自动生成客户端，防止手写英文说明重新进入项目。
- 增加当前事实源测试，要求 README 始终链接最新计划并记录唯一迁移 head。
- 延续 ADR 0003：MinIO 是开发与生产唯一对象存储，禁止 AWS/S3 客户端、后端实现和启动配置。

### 验收标准

- v2 的 P0 至 P7 完成证据可从 v3、v10、Git 历史和当前测试链路追溯，不把 GitHub 套餐限制误报为代码缺陷。
- 手写 Python 文档字符串与叙述注释通过中文语境守卫，项目源代码不再遗留纯英文业务注释。
- README 最新计划、迁移 head、MinIO 边界与仓库当前状态一致。
- Ruff、Pyright、pytest、Web 完整检查、Playwright、迁移 head 与差异检查全部通过，并使用中文 Conventional Commit 独立提交。
