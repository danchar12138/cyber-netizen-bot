# 赛博网友机器人增量开发计划

> 版本：2026-09-11-v15
> 阶段：中文产品语境与 MinIO 唯一存储收口
> 状态：已完成

## 目标

- 让管理后台和 OpenAPI 文档采用中文优先的产品语境，技术缩写只在有助于识别时保留。
- 保持现有稳定 operation ID 与生成式客户端兼容，同时消除 FastAPI 自动生成的纯英文摘要和成功响应说明。
- 将 MinIO 唯一对象存储决策固化为可自动回归的架构约束，不改写历史计划。

## 实现大纲

1. 为全部 API 标签、操作摘要、成功响应说明和文档元信息建立统一中文化规则；缺少显式摘要时从中文接口说明安全生成。
2. 将后台主导航、智能体、提示词、模型服务、适配器、入站箱和任务进程等用户可见文案调整为中文优先。
3. 同步配置注册表、健康详情、审计标签、README、OpenAPI 契约与生成式 TypeScript 客户端。
4. 增加 OpenAPI 中文契约、后台关键标签和对象存储实现边界测试。

## 验收条件

- 133 个现有 HTTP 操作均具有中文摘要，API 标签与成功响应说明不再使用 FastAPI 默认英文文案。
- 后台主要入口与管理页面不再单独使用 Agent、Provider、Adapter、Inbox、Worker 或 Prompt 作为功能名称。
- 生产组合根只装配 MinIO；依赖、启动字段和对象存储实现类的架构测试拒绝新增 AWS/S3 后端。
- Python、Web、Playwright、OpenAPI、生成式 SDK 和包构建全部通过，提交推送后 GitHub CI 全绿。

## 暂不包含

- 不翻译 API 字段名、operation ID、数据库枚举、平台品牌名或行业通用协议缩写，避免破坏契约。
- 不改写旧版计划中的历史技术选型描述。
- 不新增 Telegram 入站或媒体能力，也不改变任何外部平台副作用边界。
