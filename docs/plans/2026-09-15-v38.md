状态：已完成

## 给 AI 的开发大纲

### 目标

在 v37 告警下钻与重放复核基础上，把处置事件和重放复核事件纳入统一数据生命周期管理，使管理员无需手改配置即可控制保留期并导出当前 Agent 的安全运营历史。

### 实现范围

- 增加处置事件、重放复核事件两项版本化保留天数配置，仅允许系统或租户作用域，并在配置中心与数据生命周期页展示最终生效值。
- 扩展现有保留期清理，用租户隔离、固定批量上限分别删除到期处置事件和重放复核事件，运行证据只记录计数与截止时间。
- 新增当前 Agent 告警运营历史 JSON 导出，支持受限时间窗口，复用现有导出记录数、字节上限、权限、完整性摘要和一次性下载约束。
- 导出仅包含生命周期定位字段、处置动作、稳定复核原因码、操作者和时间，不包含任务载荷、通知目标、Secret、Prompt、隐藏推理或业务正文。
- 同步领域枚举、应用端口、PostgreSQL 与内存仓储、迁移、API、OpenAPI 客户端、中文管理后台、运行手册和测试。

### 验收标准

- 保留清理严格按租户和各自截止时间执行，单类单批不超过配置上限，未到期记录不受影响，运行证据计数准确。
- 导出严格隔离租户和当前 Agent，超窗口、超记录或超字节稳定拒绝，不落盘并返回 SHA-256 与运行记录 ID。
- 新配置可由管理后台版本化修改和校验，无需环境变量或手工配置文件。
- API、Worker、Web、迁移、文档和生成客户端一致，完整检查通过。

### 实际验收

- 完整后端门禁通过：Ruff 格式与规则、Pyright、352 项 Pytest，总覆盖率 75%。
- Web 门禁通过：OpenAPI 漂移检查、ESLint、TypeScript、27 项 Vitest 与生产构建。
- OpenAPI 共 162 个操作，迁移保持单一 head `20260915_0033`，桌面与 390px 移动端视觉检查通过。

### 后续阶段

- 在人工确认和策略护栏下提供自动化处置建议。
