# 赛博网友机器人开发计划

> 版本：2026-09-13-v20
> 阶段：渠道告警、重放来源链与健康趋势
> 状态：开发中

## 目标

让管理后台能够按错误类型识别渠道风险，追踪出站任务的重放来源，并保留 Telegram/Webhook 健康快照用于趋势查看。所有接口只返回聚合数据和安全摘要，不返回消息正文、Token、Webhook Secret 或远端错误原文。

## 开发范围

- 领域层增加渠道健康快照、错误类别和告警策略结果；保持与 FastAPI、SQLAlchemy、厂商 SDK 解耦。
- 配置中心增加渠道告警开关、错误码白名单、最低严重级别、冷却窗口、失败率和健康降级阈值，并同步校验、管理 API 与 Web 配置页面。
- Channel Repository 提供内存与 PostgreSQL 健康快照写入/查询及租户隔离；Telegram 连接测试和 Webhook 状态读取写入安全快照。
- Observability 增加按错误码/错误类别的渠道告警，支持按配置过滤、冷却和严重级别，复用现有确定性告警模型。
- Background Task API 增加重放来源链查询与安全展示；保留 `replayed_from_id` 兼容已有数据，明确出站任务与重放任务的关联。
- 新增健康趋势查询 API，Web 渠道管理页展示告警策略、趋势快照和重放来源入口。
- 同步 Alembic、OpenAPI、TypeScript SDK、单元/集成测试和 README。

## 验收

- 告警只由配置启用的错误类型触发，达到失败率或连续降级阈值时返回稳定 code、severity 和聚合数值；冷却窗口内不重复生成相同告警。
- 健康趋势按租户、Agent、渠道和时间窗隔离，快照不包含完整 URL、凭证、消息正文或远端错误文本；无数据时返回空列表和时间窗。
- 重放任务能查询直接来源及完整来源链，跨租户或未知任务返回 404，响应不暴露业务 payload。
- 内存仓储和 PostgreSQL 仓储语义一致，迁移可从 `20260910_0021` 升级，API/Web 契约生成物无漂移。
- `uv run pytest -q`、`uv run pyright`、`uv run ruff check .`、`uv run ruff format --check .`、`uv run alembic heads`、Web lint/typecheck/test/build 全部通过。

## 后续

接入真实通知投递器（邮件、飞书或 Webhook）和按租户的告警确认/抑制审计，并继续完善跨平台 Adapter。
