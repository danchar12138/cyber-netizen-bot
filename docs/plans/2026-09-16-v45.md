# 赛博网友机器人开发计划

版本：2026-09-16-v45
主题：告警建议回放证据绑定与草稿防过期
状态：已完成

## 给 AI 的开发大纲

### 目标

将候选阈值场景回放结果绑定到配置草稿创建请求。管理员只能基于当前 Agent、当前配置版本和服务端重算一致的回放证据创建草稿，避免使用过期或被数据/配置变化影响的回放结果。指纹仅覆盖安全聚合字段，不包含正文、Prompt、隐藏推理、Secret、任务载荷或自由文本。

### 实现范围

- 为回放分析增加服务端生成的 SHA-256 证据指纹。
- 配置草稿命令要求提交回放指纹；服务端重新计算回放并进行恒定时间比较。
- 回放数据、配置版本或候选值变化后拒绝过期草稿请求，并返回可理解的冲突错误。
- 管理后台保存当前回放指纹，创建草稿时自动提交；回放不可用或指纹缺失时不允许提交。
- 同步 OpenAPI、TypeScript SDK、README/运维文档及单元、集成、客户端和 Playwright 测试。

### 关键规则

- 指纹输入只允许窗口、配置版本、反馈/生命周期数量及候选阈值聚合统计等安全元数据。
- 指纹不作为授权凭证，不改变租户、Agent、权限和配置发布边界。
- 服务端永远重新解析当前配置并重算回放，客户端不得提交任意阈值、配置键或原始数据。
- 指纹匹配只允许创建仍需人工校验、审核和发布的草稿；不自动调参、不自动发布。

### 验收标准

- 缺失、错误、过期和跨 Agent 回放指纹均被拒绝；匹配指纹可创建草稿。
- 回放响应、草稿命令、API、SDK、后台 UI 和文档保持一致，且不泄露敏感数据。
- Ruff、Pyright、pytest、Web lint/typecheck/test/build、Playwright、OpenAPI 生成、迁移 head 和差异检查通过。
- 使用中文 Conventional Commit 提交并推送到 `origin/main`。

### 完成结果

- 回放分析增加只覆盖安全聚合字段的 SHA-256 证据指纹；校准窗口固定到分钟边界，避免相邻管理请求产生无意义的证据漂移。
- 配置草稿命令要求提交回放指纹和窗口结束时间，服务端按当前租户、Agent 和生效配置重新回放，并使用恒定时间比较拒绝错误、过期、跨 Agent 或配置版本不一致的证据。
- 管理后台自动绑定当前回放证据；缺失回放或指纹时不允许创建草稿，草稿仍需人工校验、审核和单独发布。
- 已同步 OpenAPI、TypeScript SDK、集成 API、应用单测、客户端测试和 Playwright 流程；未引入正文、Prompt、隐藏推理、Secret 或任务载荷。

### 验证结果

- v45 专项应用单测、API 集成测试、Web API 客户端测试和类型检查通过。
- 完整质量门禁、OpenAPI 漂移、迁移 head、差异检查和 Playwright 结果记录于本阶段提交。
