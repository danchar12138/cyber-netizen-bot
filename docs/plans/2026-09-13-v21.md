# 赛博网友机器人开发计划

版本：2026-09-13-v21
主题：告警通知投递与按租户确认抑制审计
状态：开发中

## 目标

把渠道运营告警从只读聚合升级为可通知、可确认、可抑制、可审计的管理能力，并保持租户、Agent、渠道隔离和敏感信息不泄漏。

## 开发范围

- 增加告警稳定键和按租户持久化的确认、抑制处置记录，支持确认、抑制、解除抑制。
- 增加通用 HTTPS Webhook 通知器：可配置目标、超时、重试、幂等键和 SecretStore 引用；使用 HMAC 签名，限制 SSRF 风险。
- 增加通知投递结果与安全审计记录；payload 只包含告警 code、级别、渠道和聚合指标，不包含消息正文、任务 payload、凭证、Token、Secret 或远端原始错误。
- 同步领域层、应用服务、内存/PostgreSQL 仓储、迁移、管理 API、OpenAPI、TypeScript SDK 和 Web 管理后台。
- 管理后台支持告警状态处置及通知器配置，Secret 只显示是否已配置，不允许回显明文。

## 验收标准

- `uv run pytest -q`、`uv run pyright`、`uv run ruff check .`、`uv run ruff format --check .`、`uv run alembic heads` 全部通过。
- Web lint、typecheck、test、build 全部通过，告警处置和通知器页面可用。
- API 跨租户、跨 Agent、跨渠道访问返回 404/403，不泄漏告警详情或 Secret。
- Webhook 仅允许 HTTPS、无用户密码 URL；失败重试有上限，使用幂等键和安全错误码。
- 每次确认、抑制、解除抑制和通知投递都留下不可泄漏敏感信息的审计记录。

完善邮件/飞书通知 Adapter、通知投递后台任务与退避队列，并补充多平台 Adapter 的真实连通性测试。
