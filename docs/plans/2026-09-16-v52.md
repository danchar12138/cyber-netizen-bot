# 赛博网友机器人开发计划

版本：2026-09-16-v52

主题：拟人质量同源基线差异与样本门槛

状态：已完成

## 给 AI 的开发大纲

### 目标

在 v51 时间趋势和完整冻结快照基础上，为当前 Agent 增加有明确可比性约束的基线差异。每个评测集与模型同源分组只比较最新冻结快照和紧邻的上一冻结快照；管理人员可以看到自动回归通过率与盲评评分的观察差异，同时清楚知道样本门槛、比较上下文和不可比较原因，不把多变量快照差异描述为因果结论。

### 实现范围

- 在纯 Domain/Application 层增加同源比较键、基线比较摘要和自动回归/盲评独立可比状态。
- 复用 v51 的有界安全样本与完整冻结快照聚合，不新增数据库查询、迁移或运行配置。
- 扩展质量历史 API 契约，返回双方样本数、固定最小门槛、候选与基线完整快照，以及满足门槛时的观察差值；同步 OpenAPI 和生成式 TypeScript SDK。
- 在评测实验室增加“同源基线差异”区域，展示同评测集、同 Provider/Model 约束、样本充分状态和非因果说明。
- 增加单元、API 集成、Web 单测和 Playwright 主路径覆盖。

### 关键规则

- 同源分组必须同时匹配评测集键、评测集版本、Provider 和 Model；候选是组内最新完整冻结快照，基线是紧邻的上一完整冻结快照。
- 自动回归与盲评分别要求候选和基线至少 5 个对应样本；两类证据独立判断，任一侧不足时该类差值必须为 `null`。
- 自动回归只输出通过率百分点差；盲评只输出候选回答与参考回答的平均评分差，不计算或暗示统计显著性、置信区间、单变量归因或优劣结论。
- 没有同源上一快照时返回空比较集合；快照相同不得自比较，排序必须确定且可测试。
- 只返回安全聚合与版本元数据，不返回评测输入、回答正文、评审备注、Prompt、Secret 或隐藏推理。
- API 继续只要求 `cognition:read`，保持租户和当前 Agent 隔离；查询不得触发回放、盲评领取、自动调参、发布或其他副作用。
- Domain/Cognition 不依赖 FastAPI、SQLAlchemy、Dramatiq、MinIO SDK 或厂商 SDK。

### 验收标准

- 同一窗口内有两个以上同源冻结快照时，只返回最新快照相对紧邻基线的一条确定性比较；不同评测集版本或模型不得混入。
- 双方达到 5 个运行样本时返回通过率百分点差，否则明确显示样本不足且差值为 `null`。
- 双方达到 5 份盲评时返回候选与参考平均评分差，否则明确显示样本不足且差值为 `null`。
- Web 展示比较约束、双方完整快照、样本门槛与非因果提示；无同源基线和证据不足均有真实空状态。
- OpenAPI/SDK、中文标签、测试与文档一致；无数据库迁移或新增运行配置。
- Ruff、Pyright、pytest、Web lint/typecheck/test/build、Playwright、OpenAPI 漂移、`git diff --check` 通过。
- 使用中文 Conventional Commit 提交并推送到 `origin/main`。

## 后续阶段

完成显式基线差异后，再评估由人工选择基线、冻结比较报告和可复现导出组成的评测决策记录；仍不得自动调参、自动发布或根据观察差异执行高风险动作。
