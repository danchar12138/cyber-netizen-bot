# 赛博网友机器人增量开发计划

> 版本：2026-09-10-v8
> 阶段：长对话分层摘要与预算化上下文压缩
> 状态：已完成

## 目标

- 在长会话中稳定保留当前消息、最近对话、长期记忆和较早交流脉络，避免固定条数截断造成关系与话题突然失忆。
- 在纯认知包实现可回放、无厂商依赖的分层摘要与预算压缩基线；摘要只作为不可信背景，不能覆盖系统策略或当前用户意图。
- 按 Agent 管理历史读取范围、最近消息窗口、摘要分块、最大层级与摘要预算，无需修改配置文件。
- 认知 Trace 只记录压缩数量、层级和 Token 估算，不持久化消息正文、完整摘要或模型输入。

## 实现大纲

1. 扩展上下文来源类型和压缩报告，加入确定性摘要节点 ID、覆盖消息数、层级和安全 Token 估算。
2. 将较早消息按固定窗口生成第一层说话人摘要；预算不足时继续聚合为更高层摘要，最近窗口和当前触发消息保持逐条上下文。
3. 使用 Run 冻结的配置先确定仓储读取上限，再执行压缩与最终全局 Token 选择；摘要在模型请求中按检索背景进行不可信内容封装。
4. 新增启用开关、历史读取上限、最近消息数、分块大小、最大层级和摘要 Token 预算配置，复用配置 Schema、管理 API、发布/回滚和后台表单。
5. 在安全认知轨迹中展示是否压缩、覆盖消息数、摘要层级、摘要片段数和估算 Token，不展示正文或摘要内容。

## 验证与完成标准

- 覆盖无需压缩、单层摘要、多层聚合、摘要预算裁剪、必需当前消息保留和确定性重放。
- 覆盖配置定义、冻结版本读取、长会话仓储读取上限和模型请求中的摘要安全封装。
- 运行记录、日志、Trace 与任务摘要不新增消息正文、完整摘要、Prompt、对象键或模型原始响应。
- Python 使用 `uv` 通过格式、Ruff、Pyright 和全量测试；Web 通过类型、测试、构建和 Playwright；Alembic 保持单 head。
- README 与计划状态同步，并使用带中文描述的 Conventional Commit 独立提交。

## 暂不包含

- 不调用模型生成摘要；模型增强需增加结构化输出校验、隐私分级、离线回放评测与失败降级。
- 不新增独立摘要数据表；本阶段从冻结消息窗口即时、确定性构建，避免引入陈旧摘要和额外删除一致性问题。
- 不接入真实飞书、Discord 或 Telegram API，也不在本阶段实现多模型反思对比。
