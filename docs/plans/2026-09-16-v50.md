# 赛博网友机器人开发计划

版本：2026-09-16-v50

主题：拟人评测与告警运营统一质量概览

状态：已完成

## 给 AI 的开发大纲

### 目标

在 v49 告警建议证据摘要基础上，把拟人自动回归、匿名盲评和告警建议人工反馈汇总到评测实验室的统一只读质量概览。管理人员可以在一个视图内判断当前 Agent 的拟人质量证据是否充分、自动门禁表现、人工偏好和告警建议复核结果，同时保持不同统计口径明确，不把相关性解释为因果关系。

### 实现范围

- 在纯 Domain/Application 层增加统一质量概览、数据覆盖状态和只读编排服务。
- 增加同时要求认知读取与运行轨迹读取权限的聚合 API；评测使用当前 Agent 全历史聚合，告警建议使用明确的有界时间窗口。
- 同步 OpenAPI、生成式 TypeScript SDK、Web API 封装和评测实验室页面。
- 增加单元、API 集成、Web 单测和 Playwright 主路径覆盖；不新增数据库迁移或运行配置。

### 关键规则

- 只组合已有安全聚合，不返回评测回答正文、告警正文、Prompt、Secret、任务载荷或隐藏推理。
- 响应必须明确统计口径、生成时间、数据覆盖状态和各类样本数；数据不足时不得伪造结论。
- 统一概览不得触发回放、盲评领取、告警处置、配置草稿、自动调参或自动发布。
- API 同时要求 `cognition:read` 与 `trace:read`，并保持租户和当前 Agent 隔离。
- Domain/Cognition 不依赖 FastAPI、SQLAlchemy、Dramatiq、MinIO SDK 或厂商 SDK。

### 验收标准

- 单一请求可返回拟人评测报告、告警建议质量、覆盖状态和 `automatic_actions_allowed=false`。
- 页面清晰展示全历史与窗口统计口径，缺少任一类数据时显示真实的空数据状态。
- 缺少任一权限时拒绝聚合访问；切换 Agent 后查询缓存和结果同步隔离。
- OpenAPI/SDK、中文标签、测试与文档一致；无数据库迁移。
- Ruff、Pyright、pytest、Web lint/typecheck/test/build、Playwright、OpenAPI 漂移、`git diff --check` 通过。
- 使用中文 Conventional Commit 提交并推送到 `origin/main`。

## 后续阶段

完成统一质量概览后，再增加时间趋势和版本对比；仍不得自动调参、自动发布或根据相关性数据自动执行高风险动作。
