# 赛博网友机器人增量开发计划

> 版本：2026-09-10-v12
> 阶段：用户身份可见性与管理会话治理
> 状态：已完成

## 目标

- 将现有 OIDC 身份、角色来源、管理会话和会话成员从数据库内部信息升级为可管理的用户详情闭环。
- 管理后台选择单个用户后，能够在同一页面看清当前租户、角色来源、外部身份绑定、管理会话和参与会话。
- 支持显式确认并审计地撤销指定管理会话，且任何接口都不返回访问令牌或令牌摘要。

## 实现大纲

1. 在 Domain/Application 中增加用户身份详情、外部身份、角色分配、管理会话和会话成员的纯业务投影与仓储端口。
2. 内存仓储提供开发环境投影；PostgreSQL 仓储按租户和用户聚合现有 `tenants`、`users`、`external_identities`、`role_assignments`、`admin_sessions`、`conversation_members` 数据。
3. 新增用户详情 API 与管理会话撤销 API；撤销要求逐字确认，重复撤销返回冲突，并写入不含令牌信息的审计记录。
4. 在“用户与身份”页增加单用户身份治理面板，展示角色来源、OIDC 绑定、会话成员和会话状态，并提供受权限控制的撤销动作。
5. 增加应用服务、API 与 Playwright 测试，并同步 OpenAPI 和生成式 TypeScript SDK。

## 验收条件

- 用户详情严格按当前租户隔离，越权访问用户或会话返回不存在。
- API、审计、日志和页面均不出现访问令牌或不可逆令牌摘要。
- 管理会话撤销必须准确输入确认短语，成功后状态立即更新并阻止同一令牌再次认证。
- 开发身份清楚标记为“本地开发环境”，不会伪装成 OIDC 绑定。
- Python、Web、Playwright、OpenAPI、Alembic 单 head 和远端 CI 全部通过。

## 暂不包含

- 本阶段不新增用户级限流字段、临时封禁或手工角色覆盖；这些作为后续身份策略阶段独立实现。
- 不允许后台创建未经 OIDC 验证的外部身份绑定。
- 不改变正式 OIDC 启动配置和 MinIO 唯一对象存储边界。
