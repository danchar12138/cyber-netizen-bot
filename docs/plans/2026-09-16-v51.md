# 赛博网友机器人开发计划

版本：2026-09-16-v51

主题：拟人评测质量时间趋势与冻结版本对比

状态：已完成

## 给 AI 的开发大纲

### 目标

在 v50 统一质量概览基础上，为当前 Agent 增加有界的拟人评测质量趋势和冻结版本快照对比。管理人员能够按 7、30、90 天窗口观察自动回归与盲评证据的变化，并比较由评测集、配置、人格、提示词、策略、模型路由和模型共同定义的完整运行快照；页面只陈述观察事实，不把不同上下文中的相关性解释为单一版本造成的因果变化。

### 实现范围

- 在纯 Domain/Application 层增加质量样本集、时间桶、冻结版本摘要和只读聚合服务。
- 扩展内存与 PostgreSQL 评测仓储，按租户、当前 Agent 和运行时间窗口读取已有回放及关联盲评；不新增数据库迁移。
- 增加只要求 `cognition:read` 的只读质量历史 API，同步 OpenAPI、生成式 TypeScript SDK 和 Web API 封装。
- 在评测实验室增加 7/30/90 天分段窗口、连续趋势视图、真实空状态和冻结版本对比表。
- 增加单元、API 集成、Web 单测和 Playwright 主路径覆盖；不新增运行配置。

### 关键规则

- 趋势按回放 `created_at` 归桶；盲评归属到其对应运行的时间桶，而不是提交时间，响应必须明确这一口径。
- 版本摘要必须按完整冻结快照分组，不得只按人格版本聚合后暗示单变量因果关系。
- 只返回计数、比率、版本号、模型标识和时间范围，不返回评测输入、候选回答、参考回答、评审备注、Prompt、Secret 或隐藏推理。
- 空时间桶必须保留；没有两个冻结快照时明确标记不可比较，不伪造趋势或结论。
- API 保持租户和当前 Agent 隔离；查询不得触发回放、盲评领取、自动调参、配置发布或其他副作用。
- Domain/Cognition 不依赖 FastAPI、SQLAlchemy、Dramatiq、MinIO SDK 或厂商 SDK。

### 验收标准

- 单一请求返回明确的生成时间、窗口、桶宽、归属口径、连续时间桶、冻结版本摘要和样本总数。
- 时间桶准确聚合运行数、门禁通过数、平均通过率及关联盲评结果；版本摘要准确聚合完整冻结快照。
- 非法窗口或桶宽得到 422；缺少 `cognition:read` 得到 403；跨租户或 Agent 不泄露数据。
- Web 切换 7/30/90 天窗口时查询键、标签和数据同步更新；桌面和移动端均无横向页面溢出。
- OpenAPI/SDK、中文标签、测试与文档一致；无数据库迁移或新增运行配置。
- Ruff、Pyright、pytest、Web lint/typecheck/test/build、Playwright、OpenAPI 漂移、`git diff --check` 通过。
- 使用中文 Conventional Commit 提交并推送到 `origin/main`。

## 后续阶段

完成趋势与冻结版本对比后，再评估具备最小样本门槛、同评测集与同模型约束的显式基线差异；仍不得根据观察数据自动调参、自动发布或执行高风险动作。
