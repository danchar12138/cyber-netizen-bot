# 赛博网友机器人增量开发计划

> 版本：2026-09-10-v11
> 阶段：运营总览与真实依赖健康闭环
> 状态：已完成

## 目标

- 将管理后台首页升级为可直接值守的运营总览，集中展示服务、Agent Run、模型成本、任务、错误、渠道与告警。
- 复用现有可观测性、任务和渠道能力，不新增重复真相源。
- 在启用深度就绪检查时，让系统总览返回 PostgreSQL、Redis 与 MinIO 的真实探测结果。
- 保持多 Agent 隔离：渠道数据随后台当前 Agent 切换，租户级指标明确按全局口径展示。

## 实现大纲

1. 调整 `/api/v1/system/overview`：API 进程始终报告健康；深度检查开启时调用统一依赖探针，关闭时逐项返回带说明的待探测状态。
2. 重构运行总览页：并行读取系统总览、任务状态、可观测聚合和当前 Agent 渠道实例，并按权限启用对应查询。
3. 首页展示 Agent Run 成功率、模型 Token/冻结成本、API 5xx、任务积压、Worker、依赖健康、渠道健康和近期活动告警。
4. 为可观测、任务和渠道详情提供后台内链；部分权限不可用或单项接口失败时，其余总览仍可使用。
5. 增加 API 集成测试和 Playwright 管理首页主路径，覆盖真实依赖探测、中文运营指标、多 Agent 请求头与无障碍扫描。

## 验收条件

- 深度检查开启时，系统总览中的依赖状态与注入探针结果一致；关闭时不会触发外部探测。
- 首页无需进入子页面即可判断 Agent、模型、API、任务、Worker、渠道和告警状态。
- 切换 Agent 后渠道查询使用对应 `X-CNB-Agent-ID`，租户级指标不被误标为单 Agent 数据。
- Python 全量门禁、Web 检查、Playwright、Alembic 单 head 与 `git diff --check` 全部通过。
- 使用带中文描述的 Conventional Commit 独立提交并推送，远端 CI 通过。

## 暂不包含

- 不新增指标表、告警规则或运行配置。
- 不在本阶段扩展 OIDC 身份治理、真实外部工具执行或新增 IM 事件类型。
- 不改变 MinIO 唯一对象存储边界。
