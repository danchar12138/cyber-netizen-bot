# 拟人表现自动回归与人工盲评手册

## 目标

评测闭环把两类证据分开保存：确定性自动质量门验证行动选择、回复存在性和明确文本规则；人工匿名 A/B 评审衡量人格一致、自然度、共情理解和边界尊重。自动检查不冒充主观语言质量裁判，人工评分也不能覆盖安全边界失败。

## 数据边界

- 评测集应使用合成输入或已完成授权、脱敏的数据，不得直接复制生产用户隐私、密钥、访问令牌、完整系统 Prompt 或隐藏推理。
- 自动回放会有意保存评测输入、候选回答和人工参考回答，用于可重复审查；这些正文不会进入日志、Trace、告警或模型调用指标。
- 评测只调用当前发布的认知资源与模型，不开放工具执行，不产生消息发送、文件写入或其他外部副作用。
- 盲评任务响应只包含用例分类、输入和随机化的回答 A/B，不包含运行 ID、Provider、模型、认知版本、自动检查结论或候选位置。
- 评审提交后，服务端才把左右评分映射为候选/参考评分。`candidate_is_a` 只保存在服务端任务表，不通过 API 返回。

## 标准流程

1. 在管理后台进入“评测实验室”。首次可直接运行内置 5 项拟人安全基线。
2. 如需业务评测集，点击“新建评测集”，设置稳定资源键、名称、最低通过率、最大输出 Token，并编辑完整用例 JSON。
3. 保存后检查草稿版本，再点击“发布”。同一资源键每次发布都会原子替代旧发布版本，历史版本和历史运行不变。
4. 在“回归目标”选择已发布评测集，点击“运行自动回归”。运行会冻结配置、Persona、Prompt、Policy、模型路由、Provider、模型、Token 与估算成本。
5. 在“自动回放历史”查看逐项质量门。质量门失败时先修复确定性行为或显式文本规则，不进入发布候选。
6. 评审人员点击“领取下一条”，独立阅读回答 A/B，对两侧四个维度分别给 1–5 分，再选择总体偏好并提交。
7. 汇总区观察候选/参考均分和胜/平/负数量。至少由多名评审覆盖关键分类后，再决定是否发布认知或模型版本。

## 评测集用例字段

- `case_key`：评测集版本内唯一的稳定键。
- `category`：例如自然度、人格一致性、共情、关系边界、拒答与策略。
- `input_text`：送入认知运行时和模型的不可信用户输入。
- `expected_action`：`reply`、`ask`、`wait`、`no_reply` 或 `tool`。
- `reference_response`：供匿名比较的人工参考回答；`reply` 与 `ask` 用例必须提供，静默类用例应为 `null`。
- `required_phrases`：候选回答必须包含的明确短语，仅用于可客观判断的协议或边界措辞。
- `forbidden_phrases`：候选回答不得包含的明确短语，不要用它代替人工自然度评价。

## 判读原则

- 自动门禁通过率必须达到评测集冻结的 `minimum_pass_rate`。发布安全关键版本时建议保持 100%。
- 人工分数按每侧四维等权平均；同时保留总体偏好，避免只看平均分掩盖明显比较差异。
- 同一评审对同一运行结果只能提交一次；未提交的已领取任务会稳定返回，不会因刷新交换 A/B。
- `development/friendly-echo-v1` 只用于验证链路，不代表拟人质量基准。真实候选应使用配置中心发布的生产候选模型和版本化用途路由。
- 不同评测集版本、Persona、Prompt 或模型的结果不可直接混为一次对照实验；比较时先核对运行详情中的冻结版本。

## 主要 API

- `GET/POST /api/v1/evaluations/suites`
- `POST /api/v1/evaluations/suites/{suite_id}/publish`
- `GET/POST /api/v1/evaluations/runs`
- `GET /api/v1/evaluations/runs/{run_id}`
- `POST /api/v1/evaluations/blind-assignments`
- `POST /api/v1/evaluations/blind-assignments/{assignment_id}/reviews`
- `GET /api/v1/evaluations/report`

评测集管理使用认知读写权限，运行和完整结果使用 `cognition:evaluate`，匿名领取与提交使用独立的 `evaluation:review`。只读评审人员可参与盲评，但不能读取带来源字段的完整运行详情。

## 故障处理

- 模型不可用：确认配置中心中的 Provider、模型名称、版本化用途路由和密钥状态；API 只返回安全错误类型，不回显凭证或底层响应。
- 单条生成失败：运行仍会保存，`generation_completed` 检查失败并记录安全错误类型，便于重现同一版本组合。
- 没有待评审任务：先完成一次包含可回复用例和参考回答的自动回放；同一评审已处理完当前范围时会返回空任务。
- 发布冲突：只有草稿可发布；要修改已发布评测集，应使用同一资源键新建更高版本再发布。
